# RAG Architecture Flows

Three flows of increasing complexity — read in order, since each builds
on the previous one's components.

- [basic-rag.md](basic-rag.md) — the minimal end-to-end shape
- [enterprise-rag.md](enterprise-rag.md) — adds auth, policy, reranking,
  multi-model routing, observability, caching
- [agentic-rag.md](agentic-rag.md) — retrieval becomes a tool an agent
  chooses to invoke, rather than a fixed pipeline stage
