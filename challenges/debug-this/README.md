# Debug This

Each challenge gives you real evidence from a broken system. Investigate
before opening `solution.md`.

## Available

- [03-oomkill/](03-oomkill/README.md)

## How to use these

1. Read `README.md` for the situation and evidence only.
2. Open the files under `evidence/` yourself and form a hypothesis.
3. Only then open `solution.md`.

This mirrors real on-call debugging far better than reading a scenario
with the answer already attached.
