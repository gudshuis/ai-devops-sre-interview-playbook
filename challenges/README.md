# Challenges

Hands-on practice, split into two modes:

- [debug-this/](debug-this/README.md) — given evidence from a broken
  system, investigate and diagnose before reading the solution
- [design-this/](design-this/README.md) — given a design brief, produce
  your own architecture before comparing against a reference solution

## Status

Starter content — one fully worked example per mode, demonstrating the
pattern. See [ROADMAP.md](../ROADMAP.md) for planned expansion.
