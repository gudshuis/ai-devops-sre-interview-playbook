# Learning Paths

Curated, ordered routes through the repository for specific roles/interview
targets, instead of reading every folder linearly.

Each path lists: topics in recommended order, what interviewers at that
level typically probe for, and which hands-on/architecture exercises to
prioritize.

## How to use a path

1. Read the linked `foundations`/domain content first if you're not
   already solid on it — paths assume fundamentals, they don't re-teach
   them.
2. Work through the senior-scenario and troubleshooting links **before**
   looking at the answer — the value is in the reasoning attempt, not the
   read.
3. Finish with the architecture/system-design exercise(s) listed — these
   are the closest simulation of an actual onsite round.
